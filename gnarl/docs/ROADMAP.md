# GNARL — Roadmap

| Milestone | Goal | Status |
|---|---|---|
| M0 | Minimal VST3 compiles on Windows and loads in FL Studio | In progress |
| M1 | Plugin responds to MIDI notes, produces a basic FM tone | In progress |
| M2 | Darkpsy engine: envelopes, filter, distortion, glide, presets, mutate | In progress |
| M3 | Tempo-synced 16-step pattern generator with internal playback | Planned |
| M4 | MIDI file export + live VST3 MIDI output (tested in FL Studio) | Planned |
| M5 | Stable MVP: state save, tests, manual checklist | Planned |

Each milestone ships a usable build. Windows builds are produced by
`.github/workflows/build-windows.yml` and uploaded as artifacts.
